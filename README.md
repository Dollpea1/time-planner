# Time Planner

A lightweight, clean, and responsive Time Planner web application built purely with HTML, CSS, and modern JavaScript. All task data persists locally in your browser using `localStorage`—no servers, backend, database, or login required.

## Features

- **Add Tasks**: Plan tasks with Task Name, Date, and Time.
- **Task List**: Clean, legible list displaying formatted dates and times.
- **Edit Tasks**: Update task details on the fly with a dedicated edit modal.
- **Delete Tasks**: Safe deletion with a confirmation prompt before removal.
- **Live Search**: Filter tasks in real time by name, date, or time.
- **Task Counter**: Live counter at the top showing the total number of tasks.
- **Friendly Empty State**: Helpful guidance when no tasks have been created or when a search returns no matches.
- **Persistent Storage**: Data stays saved in browser `localStorage` across page refreshes.
- **Mobile Responsive**: Fully optimized for phones, tablets, and desktop displays.

## Quick Start

Open `index.html` in any modern web browser. That's it!

## Tech Stack

- **HTML5**
- **CSS3** (Flexbox, CSS Variables, Responsive Design)
- **JavaScript** (ES6+, DOM Manipulation, LocalStorage API)
